# Student Performance & Financial Analytics

## Project Overview
An end-to-end Data Analytics project developed using **Microsoft Excel, SQL Server, and Power BI** to analyze student academic performance, attendance, and financial records.

## Tools & Technologies
- **Microsoft Excel:** Data cleaning, formatting, Pivot Tables, charts, and analysis.
- **SQL Server:** Data extraction, filtering, joins, aggregate functions, subqueries, CTEs, and window functions.
- **Power BI:** Interactive dashboards, KPI cards, visualizations, and slicers.

## Dataset Description
The project contains two datasets:

1. **Student Performance**
   - Student ID and Name
   - Gender, Age, Department, Course, and City
   - Attendance Percentage
   - Marks, Total Marks, and Grade

2. **Student Fees**
   - Fee ID and Student ID
   - Total Fees
   - Paid Fees
   - Pending Fees
   - Payment Status

## Project Objectives
- Analyze student academic performance.
- Identify students with low marks and attendance.
- Compare performance across departments.
- Analyze gender and city-wise student distribution.
- Calculate total fee collection and pending payments.
- Identify students with outstanding fee balances.
- Combine academic and financial information for student-level analysis.

## Key Analysis
- Total student count
- Average and highest marks
- Department-wise performance
- Attendance analysis
- Grade distribution
- Total fees and collected fees
- Pending fee analysis
- Student academic and financial risk analysis
